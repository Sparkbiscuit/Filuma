# Filuma 1.4.0 validation

September 9, 2026. App and widget version 1.4.0, build 10.

## Automated verification

- 225 unit tests passed, including actual migration of a baseline SwiftData store, Safe Zone inheritance/None/persistence, distributed scheduling, deadline fallback, unchanged refresh stability, earliest-start preservation, active timer protection, and durable attendance replanning.
- All 31 authored UI journeys passed across the initial run and targeted corrections: 28 applicable iPhone journeys and three iPad landscape journeys. The initial full iPhone run skipped the three iPad-only tests by design; those were run on iPad. This is combined coverage, not a claim that the initial full run was green.
- Release configuration built successfully for generic iOS, including the widget, with signing disabled. This does not produce a distribution-signed archive.
- Screenshot capture suite passed on iPhone 17 Pro Max and 13-inch iPad; dark and light appearances were captured from the app using synthetic data.
- Read-only code review found two timer/deadline issues. Both were fixed, regression-tested, and independently confirmed resolved before commit.
- Largest-text-size checks cover navigation, task editing, capture, settings, focus controls, onboarding, and Weave interaction. Test helpers were corrected for scroll momentum, offscreen content, fleeting receipts, chart hierarchy, and subpixel 44pt rounding.

## Visual verification

Reviewed actual Today, task preview, Focus, Capture, Schedule, and Weave screenshots, including light appearance and iPad layouts. A final user review caught the rectangular Focus halo and redundant time readout: the halo now fades to transparency within a circular gradient and the ring has one primary time with one status label. The detailed VoiceOver value is retained; scheduled sessions show their distinct elapsed clock below the ring.

Website image replacements were prepared from the current origin/main in isolated worktrees, preserving existing local work. The mappings are recorded in the asset README. Desktop and 390px mobile previews were checked; referenced image files exist, and the mobile pages have no horizontal overflow. The new hero uses the square artwork on mobile and wide artwork on desktop.
