# Filuma 1.4.0 · first App Store update

Prepared September 9, 2026. The app and widget are set to **1.4.0 (10)**. No App Store build has been uploaded or submitted during this work.

## What changed

Work sessions spread across available days while respecting deadlines, busy time, sleep, daily limits, locked blocks, and active timers. Safe Zone reuses the existing deadline buffer: fresh installs default to one day, existing saved preferences stay intact, and individual tasks can inherit the default or choose their own margin (including None). When necessary, the planner can use that margin to fit work before the actual deadline.

Today has a warm landscape and connected next steps. Task Preview shows the saved session plan, Schedule summarizes each task’s distribution, and Weave displays recorded effort across a week, two weeks, or a month. Native text scales with accessibility settings; light and dark appearances follow the device.

## Ready-to-paste What's New

Work, with room to breathe.

• A warmer new look for Today, focus sessions, and your Weave, in light and dark.
• Work spreads across available days to help you make steady progress.
• Set a Safe Zone before a deadline, with a default for your schedule and optional settings for each task.
• Preview upcoming sessions and see how each task fits across your week.
• Scheduling, accessibility, and reliability improvements.

Thank you for making room for Filuma in your day.

## Submit the existing app as an update

1. Open `Filuma.xcodeproj` in Xcode. Select the Filuma scheme and **Any iOS Device (arm64)**. Confirm the app and widget show version 1.4.0 and build 10. If that build number has already been used in App Store Connect, increment both targets before archiving.
2. Check signing under your existing team, then choose **Product → Archive**. In Organizer, validate the archive, then **Distribute App → App Store Connect → Upload**. Keep the existing bundle ID `com.christoforakis.Filuma`.
3. In App Store Connect, open **Apps → Filuma**, then create a new iOS version **1.4.0** using the plus button beside the platform. This is an update under the existing app record. Apple carries forward editable metadata; review it rather than creating a second app. [Apple: create a new version](https://developer.apple.com/help/app-store-connect/update-your-app/create-a-new-version/).
4. After the upload finishes processing, select build 10 (or the new number you used). Paste What's New above. Replace the screenshots with the new matching iPhone and iPad sets. Keep the existing privacy/support URLs and check that the description still accurately says the free tier permits up to three active tasks.
5. Review export compliance, App Privacy, age rating, and App Review contact information. Confirm the declarations still describe the actual integrations and data behavior. Do not claim accessibility support solely from these simulator checks.
6. Choose manual release if you want to decide when the update goes live. A phased release is also available for an update. Add the version for review, then submit the pending submission. [Apple: submit an app](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/submit-an-app).
7. Once approved, release it using the selected option. Remove the “upcoming 1.4 update” image notes on both websites when it is live.

## App Review notes supplement

This update introduces distributed scheduling, a per-task Safe Zone before the deadline, and a visual refresh. The core scheduling workflow requires no account. The free tier supports up to three active tasks. To inspect the changes, add a multi-hour task due several days ahead, open Scheduled sessions from Today, and view Schedule → Week. Safe Zone can be adjusted in the task’s scheduling options and in Settings. Existing user data and saved global buffer preferences are preserved.

Retain any existing review instructions for optional calendar connections or purchases. The synthetic screenshot fixture is only activated by UI-test launch arguments and is not an onboarding flow.
